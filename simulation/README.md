# Simulation Files

This folder contains LTspice simulation files for the Buck Converter.

## Files

| File | Description |
|---|---|
| buck_24V_5V_openloop.asc | Main LTspice schematic (open-loop) |

## How to Open

1. Install LTspice (free from analog.com)
2. Open the .asc file
3. Press F9 to run the simulation
